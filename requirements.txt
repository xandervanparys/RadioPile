# RadioPile — core dependencies.
#
# Everything needed to build datasets, validate them, generate figures, and run
# the test suite.
#
#     ./setup_env.sh        (or: pip install -r requirements.txt)
#
# Requires Python 3.11 to 3.13 (see .python-version). The v1.0 release was
# built and validated on CPython 3.11.15.
#
# Versions are pinned to the environment the v1.0 corpus was built and validated
# with. A data descriptor's reproducibility claim is only as good as its
# dependency set, so prefer changing these deliberately over letting resolution
# drift. To upgrade, bump here and re-run `pytest tests/`.
#
# TensorFlow is deliberately NOT here — it is needed only by the paper baselines
# in ml-baselines/, and lives in requirements-ml-baselines.txt so that the pipeline
# and its test suite stay framework-free.
